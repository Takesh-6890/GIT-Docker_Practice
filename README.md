# 📋 Task Tracker

A simple, elegant task tracker web application — built as a **Git & GitHub practice project**.

## 🚀 Features

- ✅ Add, complete, and delete tasks
- 🎯 Priority levels (Low, Medium, High)
- 🔍 Filter tasks (All / Active / Completed)
- 💾 Persistent storage via `localStorage`
- 🌙 Modern dark theme UI

## 📂 Project Structure

```
Git_Project(practice)/
├── index.html          # Main HTML page
├── style.css           # Styles and theme
├── app.js              # Application logic
├── data.json           # Sample data
├── README.md           # This file
├── CONTRIBUTING.md     # Contribution guidelines
├── GIT_EXERCISES.md    # 🏋️ Git practice exercises
└── .gitignore          # Git ignore rules
```

## 🛠️ Setup

1. Clone or initialize this repo
2. Open `index.html` in your browser
3. Start adding tasks!

> No build tools or servers needed — it's plain HTML, CSS, and JavaScript.
